# ArtiFix

> **Convert. Fix. Deliver.** — Universal CAD/CAM file repair, conversion and 3D viewer.

**English** | [Italiano](#-italiano)

---

## 🇬🇧 English

**ArtiFix** is a free web-based platform for the conversion, repair, and visualization of CAD/CAM and 3D mesh files. It supports 50+ formats including STL, OBJ, PLY, GLB, GLTF, FBX, 3MF, DAE, WRL, OFF, DXF and 3D PDF.

### ✨ Features

- 🔄 **Universal conversion** between 50+ 3D formats
- 🛠️ **Repair** of damaged or corrupted CAD files
- 🖥️ **Integrated 3D viewer** with interactive controls
- 📄 **Export to 3D PDF**
- 🔒 **Privacy-first** — files are processed in memory and never stored
- ⚡ **100% free**, no registration required
- 🌐 **Works in your browser** — no installation needed

### 📁 Supported Formats

**CAD:** DXF, DWG, DGN, DWT
**3D Mesh:** STL, OBJ, PLY, 3MF, FBX, GLB, GLTF, STEP, IGES, U3D, SKP
**BIM:** IFC, RVT, RFA, RTE
**Documents:** PDF, 3D PDF, DOCX, XLSX
**Geospatial:** SHP, GeoJSON, KML, GPX
**Vector:** SVG, EPS, AI, CDR
**Electronics:** BRD, SCH, PCB, GBR (Gerber)
