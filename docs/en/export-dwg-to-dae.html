Why can't ArtiFix open DWG, SKP or RVT files directly?

DWG, SKP and RVT are proprietary formats. They are owned and controlled by Autodesk (DWG), Trimble (SKP), and Autodesk (RVT). To read these files, software must use libraries that are licensed commercially by the format owners.

Because ArtiFix is a free, open platform, we cannot include these commercial libraries. That's why we can't open DWG, SKP or RVT files directly.

But don't worry. You don't need to pay for software. Every CAD application — AutoCAD, SketchUp, Revit, and others — can export the file to a universal 3D format. Once exported, the file can be uploaded to ArtiFix and converted to anything.

The recommended workflow

Export from CAD → Upload to ArtiFix → Convert to any format

Open your file in the original CAD software

Open the DWG file in AutoCAD (or compatible), the SKP file in SketchUp, or the RVT file in Revit. Any version works.

2

Export as DAE (Collada) or OBJ

Use File → Export (or Save As) and choose DAE (Collada) or OBJ as the output format. Both are universal, free, and preserve geometry.

Go to artifix.streamlit.app and upload your DAE or OBJ file. No registration required.

Convert to any 3D format

Choose the target format — STL, 3D PDF, GLB, GLTF, PLY, FBX, 3MF, WRL, OFF, DXF — and click Convert. Download the result. Done!

How to export to DAE or OBJ in your CAD software

🏗️ AutoCAD (DWG)

1. Open the DWG file
2. Type EXPORT or go to File → Export
3. Choose DAE (Collada) or OBJ
4. Save the exported file

🏠 SketchUp (SKP)

1. Open the SKP file
2. Go to File → Export → 3D Model
3. Choose OBJ or DAE (Collada)
4. Save the exported file

🏢 Revit (RVT)

1. Open the RVT file
2. Go to File → Export → CAD Formats or IFC
3. Choose IFC (recommended for BIM) or DAE
4. Save the exported file

📐 Other CAD software

Most CAD programs support exporting to DAE (Collada) or OBJ. Look for File → Export and choose either format. Both are supported by ArtiFix.

💡 Tip: DAE (Collada) preserves materials and textures better than OBJ. If your model has colors or textures, use DAE. If you only care about geometry, OBJ is simpler and faster.

Frequently asked questions

Can ArtiFix open DWG files directly?

No. DWG is a proprietary format owned by Autodesk. ArtiFix cannot read DWG files directly because they require commercial libraries. However, you can easily convert DWG files to a universal format using a simple export from AutoCAD or other CAD software.

What is DAE (Collada)?

DAE (Digital Asset Exchange) is an open XML-based 3D format, also known as Collada. It's supported by many 3D applications and CAD software as an export format. It can store geometry, materials, textures, and animations.

What formats can I export from AutoCAD?

AutoCAD and similar CAD software can export to many formats, including DAE (Collada), OBJ, STL, 3DS, FBX, and others. For ArtiFix, DAE and OBJ are the best choices because they preserve geometry and are widely supported.

Can I use ArtiFix to convert SKP (SketchUp) files?

ArtiFix cannot read SKP files directly because they are a proprietary format. However, you can export your SketchUp model to DAE or OBJ from SketchUp (File > Export > 3D Model), then upload the exported file to ArtiFix.

Can I convert RVT (Revit) files?

ArtiFix cannot read RVT files directly, as they are a proprietary BIM format. To use ArtiFix, export your Revit model to IFC, DAE, or OBJ, then upload it to ArtiFix. IFC is the recommended open format for BIM models.
