Formati 3D supportati

Il Viewer 3D di ArtiFix supporta tutti i formati 3D principali:

  • STL (STereoLithography) — il formato standard per la stampa 3D
  • OBJ (Wavefront) — il formato più diffuso nella modellazione 3D
  • PLY (Polygon File Format) — per mesh con colori per vertice
  • GLB / GLTF — formato moderno per il web (WebGL)
  • FBX (Autodesk) — per animazioni e scene complesse
  • 3MF — formato moderno per la stampa 3D
  • DAE (Collada) — formato di scambio universale
  • WRL, OFF, U3D — altri formati supportati
  • PDF — per visualizzare 3D PDF interattivi
