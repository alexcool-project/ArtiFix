Perché i file STL si danneggiano?

STL è un formato semplice, ma è anche fragile. I file possono danneggiarsi o diventare non stampabili per molte ragioni:

  • Esportazione errata dal software CAD (triangolazione incompleta o sbagliata)
  • Download interrotto o copia, con conseguente file troncato
  • Errori di conversione durante la traduzione da un altro formato 3D
  • Geometria non manifold nel modello originale (spigoli condivisi da più di due facce)
  • Normali invertite (facce che puntano verso l'interno invece che verso l'esterno)
  • Vertici duplicati o triangoli degeneri
  • Piccoli buchi dove la mesh non è chiusa

Questi problemi rendono lo STL illeggibile dagli slicer o causano errori di stampa. Riparare il file riporta la mesh a uno stato stampabile.

Domande frequenti

Riparare file STL è gratis?

Sì, ArtiFix è completamente gratuito. Non ci sono costi nascosti, abbonamenti o registrazione richiesta per riparare i tuoi file STL.

Quali tipi di errori può riparare ArtiFix?

ArtiFix può riparare molti errori comuni dei file STL, tra cui geometria non manifold, normali invertite, vertici duplicati, triangoli degeneri e piccoli buchi. Per corruzioni molto gravi, il file originale potrebbe non essere recuperabile.

Perché i file STL si danneggiano?

I file STL possono danneggiarsi per molte ragioni: esportazione errata dal software CAD, download interrotto, conversione da altri formati o generazione da un modello con geometria non manifold. Alcuni file STL sono anche non stampabili perché contengono errori geometrici dal design originale.

I miei file STL sono al sicuro durante la riparazione?

Sì. I file sono elaborati in memoria sul server e non vengono conservati dopo l'elaborazione. ArtiFix non condivide i tuoi dati con terze parti.

ArtiFix può riparare file STL molto grandi?

ArtiFix può gestire file STL fino a diverse centinaia di megabyte. Per file molto grandi (oltre 500 MB), il tempo di elaborazione potrebbe essere più lungo e alcune funzionalità potrebbero essere limitate dalla memoria disponibile sul server.
