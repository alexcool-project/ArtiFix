Riparare file STL danneggiati o corrotti

Guida passo-passo per analizzare, ripristinare e recuperare modelli 3D STL danneggiati. Gratis, online, senza installare software.

Quando un file STL è "danneggiato"?

Un file STL può risultare corrotto o danneggiato per vari motivi. I sintomi più comuni sono:

  • Il file non si apre nel software di modellazione o slicer
  • Il modello appare con facce mancanti o buchi
  • Le normali sono invertite (l'oggetto appare "al rovescio")
  • La mesh non è manifold (bordi aperti, geometria non chiusa)
  • Il file è troncato (download interrotto)
  • Sono presenti vertici duplicati o degenerati
  • Il software segnala errori di geometria

Questi problemi impediscono di solito la stampa 3D o la modifica del modello. ArtiFix può aiutarti a riparare molti di questi errori automaticamente.

Tipi di errore STL più comuni

1. Facce mancanti o buchi

Quando un file STL viene esportato male, alcune facce triangolari possono mancare. Il modello appare "aperto" e non è stampabile in 3D.

2. Normali invertite

Le normali indicano la direzione "esterna" della superficie. Se sono invertite, il modello appare nero, al rovescio, o presenta artefatti visivi.

3. Geometria non manifold

Un modello è "manifold" quando ogni bordo appartiene esattamente a 2 facce. Se ci sono bordi aperti o intersezioni, il modello non è manifold e non è stampabile.

4. Vertici duplicati o degenerati

Alcuni esportatori creano vertici duplicati o triangoli degeneri (area zero), che possono causare problemi in stampa o rendering.
